# Prism

A fast, beautiful file browser for macOS, built with Liquid Glass.

**[Download Prism for Mac](https://github.com/osmangulveren/prism-mac/releases/latest/download/Prism.dmg)**

Requires macOS 26 or later on a Mac with Apple silicon. Open the DMG and drag Prism to Applications.
If macOS says the app can’t be checked, Control-click Prism in Applications and choose Open.
